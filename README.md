# Hex Planet Brush Editor

A desktop editor for painting terrain onto a hexagonal planet with **10,080,162 cells**, built entirely on the Python standard library.

No `pip install`. No game engine. No third-party packages of any kind — the renderer talks to OpenGL through `ctypes`, the UI is `tkinter`, and the PNG codec is 300 lines over `zlib`.

---

## Why this might interest you

Most hex-planet projects stall on the same set of problems. This one has working answers for all of them, each with tests:

| Problem | What this does |
| --- | --- |
| Addressing millions of cells | Procedural frequency-1004 geodesic topology, 10,080,162 stable `CellId`s, 12 hidden pentagons handled explicitly |
| Loading a planet that does not fit in memory | 39,060 connected logical chunks, compact hierarchical visibility indexes, background reads, visible-only dense GPU instance streaming |
| Zoom without popping | Automatic LOD0–LOD4 selection with hysteresis, plus a multi-level aggregate far-view hierarchy with regenerable node caches |
| Saving without corrupting | Indexed Pack storage, per-chunk independent compression, CRC32 isolation, atomic dirty-chunk save, compaction, and interrupted-transaction recovery |
| Texture memory | Ref-counted GPU texture-array residency, grace-period release, deterministic slot reuse |
| Frame spikes while panning | Frame-budgeted visible chunk additions and removals with center-first priority |
| Seams between tiles | Four-pixel copied edge padding, nearest-neighbour sampling, six shader UV rotations, and automated seam/UV validation |

Even if you never run the editor, `apps/*.md` documents each of these as a standalone design note.

## Requirements

- **Windows** — rendering goes through WGL, and the launcher is PowerShell
- **Python 3.10 or newer, with `tkinter`**
- A GPU with OpenGL support

That is the complete list. There is no dependency file because there are no dependencies.

## Quick start

```powershell
git clone https://github.com/kiseki233/hex-planet-brush-editor.git
cd hex-planet-brush-editor
.\apps\start.bat
```

`start.bat` looks for `pwsh.exe`, falls back to `powershell.exe`, then locates a Python 3.10+ interpreter with `tkinter`. To point it at a specific interpreter, set `KISEKI_PYTHON`:

```powershell
$env:KISEKI_PYTHON = "C:\Python312\python.exe"
.\apps\start.bat
```

## The brush library ships as placeholders

`art/brushes/` contains **48 flat colour tiles across 12 categories**, generated by a script in this repository. They exist so that a fresh clone opens with a working library and the full pipeline can be exercised immediately. They are not artwork.

To use your own tiles, drop 512×512 RGB or RGBA PNG files into category folders:

```text
art/brushes/
  01-ocean-deep/
    01.png
    02.png
  54-forest/
    01.png
```

The catalog is rebuilt from whatever is on disk — there is no registration step. Category names may use any Unicode characters. The editor enforces a 4095-brush limit and assigns each tile a stable 128-bit UID that survives renames.

To regenerate or resize the placeholder set:

```powershell
python apps\tools\make_example_brushes.py --size 512 --variants 4
```

A built-in cropper (`apps/app/brush_cropper.py`, documented in `apps/IMAGE_CROPPER.md`) exports one or many correctly sized tiles from larger source images.

> **Note on assets:** make sure you hold the rights to any imagery you add. Satellite and map imagery from commercial providers is copyrighted and cannot be redistributed.

## Tests

```powershell
cd apps
python -m unittest discover -s tests
```

265 tests covering topology, chunk layout, visibility, LOD selection, aggregate digests, Pack storage and recovery, GPU batching, brush catalog behaviour, and seam validation.

## Layout

```text
apps/
  app/          52 modules: topology, storage, LOD, GPU streaming, UI
  tests/        265 tests
  tools/        placeholder brush generator and helpers
  *.md          design notes, one per subsystem
  start.bat     entry point
art/
  brushes/      brush library (placeholder tiles included)
  maps/         saved planets (empty; created on first save)
  data/         cropper output
```

Design notes worth reading first: `apps/PRODUCTION_TOPOLOGY.md`, `apps/TOPOLOGY_FORMAT.md`, `apps/PACK_COMPACTION.md`, `apps/LOD_AND_ASYNC.md`, `apps/GPU_STREAMING.md`.
